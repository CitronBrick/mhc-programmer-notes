## Physical Layer

* sends raw data as bits over physical medium
* converts data to signals that travel via fibre optics
* decides how data flows : (1 way,  2 way alternatively, 2 way simultaneously)
* modulation - demodulation

### Physical Layer - Topologies

* Point to Point configuration : dedicated line between 2 devices
* Multi Point configuration : line connects multiple devices






## Data Link layer

### Data Link layer : Responsibilities

* node-node data delivery within local network
* error free Transmission
* encoding, decoding, organizing data
* most complex layer 


### LLC : Logical Link Control

sublayer dealing with multiplexing, data flow, error messages & acks

### MAC : Media Access Controll

sublayer managing device interaction, addressing frames, physical media access.
divides packets into frames & sends them bit by bit into physical Layer

### Data Link layer : Protocol

* Synchronous Data Link Protocol (SDLC)
* High Level Data Link Protocol (HDLC)
* Serial Line Interface Protocol (SLIP)
* Point to Point Protocol (PPP)
* Link Access Procedure (LAP)
* Link Control Procedure (LCP)
* Network Control Procedure (NCP)

### Data Link Layer : Devices

* Switch
* Bridge
* Network Interface Card (NIC) : adds MAC address to frame
* WAP
* Layer 2 Switches 
 



## Network layer

### Network layer : Responsibilities

* Logical reasoning : assigns unique IP address
* Packetization 
* Host to Host delivery
* Forwarding : moves packets : router input interface -> output interface based on destination IP
* Routing 
* Fragmentation & assembly : splites big packets to fragments to match MTU (Maximum Transmission Unit) of network & reassembles at destination
* Subnetting
* Network Address Translation (NAT) : maps private IP to public IP

### Network layer : Protocols

* IPv4/IPv6 : logical addressing 
* ICMP (Internet Control Messaging Protocol) : Error reports & diagnostic messages
* ARP (Address Resolution Protocol) : maps IP address to MAC address within local network
* RARP (Reverse Address Resolution Protocol) : MAC -> IP
* NAT (Network Address Translation) : private IP -> public IP
* IPSec (Internet Protocol Security) : encryption & authentication
* MPLS (Multiprotocol Label Switching) : use labels to forward packets efficiently 

## Transport layer

* end to end delivery
* reliable & ordered data transfer
* error detection & recovery
* multiplexing & demultiplexing using port numbers
* data flow to prevent receiver overload
* divides data from upper layers to segments (TCP) or datagrams (UDP)

### 3 way handshake (ISN = Initial Sequence NUMBER)

1. SYN (Client -> Server) : Client sends SYN TCP segment with ISN=1
2. SYN ACK (Server -> Client) : Server replies SYN=1, ACK=1 containing its own ISN and ACK=client_ISN+1
3. ACK (Client -> Server) : Client replies ACK=1 with ACK=server_ISN+1. Connection becomes **ESTABLISHED** state


## Presentation layer

* Data translation: converts data generated by Application layer  into a standard form 
* encryption & decryption
* compression techniques
* Syntax & semantiques management
* System Interoperability

### Presentation layer protocols

* AFP Apple Filing Protocol
* LPP Lightweight Presentation Protocol : ISO presentation over TCP/IP
* NetWare Core Protocol (NCP) : Novell Netware for file & print services
* Network Data Representation (NDR)
* External Data Representation (XDR)
* Secure Socket Layer (SSL)
* Transport Layer Security (TLS)
