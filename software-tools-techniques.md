# Software Tools and Techniques

## Entity Relationship diagram (ER diagram)

* Structural diagram used in database design
* Major entities within system scope and inter-relationship between them
* Business objects can be : 
	* *tangible* (eg: Product)
	* *intangible* (eg: Log)
* Entity : noun, table
* Entity aligns with **DFD** *Data Store*
* Entity aligns with **BPMN** *Data Object*


### ER : Use cases

* Database design
* Database debugging
* Database creation & patching
* Recruitments gathering

### ER : Notation

* Entity - rounded rectangle
* Cardinaltiy 
	* number of possible occurences in 1 entity associated with the number of occurences in the other
	* crow's foot at connector's end

### ER models

1. Conceptual (columns absent)
2. Logical (columns present, column types optionally present)
3. Physical (column types, pk, fk present)
