# DNS & Web Hosting

* DNS = Domain Name System
* DNS convert domain name to IP address
* [RFC 1035](https://datatracker.ietf.org/doc/html/rfc1035)

1. URL is entered in web browser
2. Device contacts **resolver** (a special DNS server)
3. **resolver** queries DNS servers having the relevant domain info
4. DNS servers send `A record` to **resolver**
5. **resolver** sends `A record` to device
