# NIST Cloud Computing Reference Architecture

## NIST = National Institute of Standards & Technology


## Cloud Consumer

* Person/Organization that maintains business relationship with & uses service from Cloud Provider
* Consumer 
	1. browses service catalog
	2. requests service
	3. setups up contract with Provider
	4. uses service
* SLA 
	* technical performance requirements fulfilled by Provider
	* service quality
	* security
	* performance failure remedies
	* limitations & obligations
	* non-negotiable except for heavy users
* SaaS = Software applications
* PaaS = tools & execution resource
* IaaS = virtual computers, network accessible storage, network infra components

## Cloud Provider

* Person/Organization making a service available to the parties
* Major responsibilities
	* Service deployment
	* Service orchestration
	* Cloud services management
	* Security
	* Privacy

## Cloud Auditor

* independant examination of cloud service controls with the *intent to express an opionion* thereon
* conformance to standards
* evaluate
	* security
	* privacy
	* performance
* important for **Federal agencies**

## Cloud Broker

* a cloud consumer may request servcies from a cloud broker (instead of directly contacting cloud provider)
* **Service Intermediation** : value added services
* **Service Aggregation** : combine multiple services
* **Service Arbitration** : broker can flexibly choose which services to aggregate (may use **Credit Scoring Service**)

## Cloud Carrier

* intermediary that connects & transports  cloud services between Consumer & Provider
* network, telecommunication & other devices (eg: MID : Mobile Internet Device)
* **Transport agent** : organization that provides physical transport of storage media.
* Cloud Provider will setup SLA with Cloud Carrier
